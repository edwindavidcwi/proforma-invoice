🌟What is this game?

It looks like a Game Boy adventure, but it's really a learning game. As your child plays and battles, the game asks a school question — answer it right and the move works! Get it wrong and it gives a friendly hint and lets you try again. Nobody is ever punished for a mistake.

💚 The goal: Ethan practises reading, maths, and more without it feeling like homework.

▶️Getting started

  1. Open Pokemon Quiz (the Windows app, or the app on the phone).
  2. Press Start (the Enter key, or tap Start) to begin a new game and follow the short intro.
  3. Walk around with the arrow keys. When a battle begins, choose FIGHT then a move — that's when a question pops up!

  1. Read the question at the top (or let the game read it aloud — see below).
  2. Use the arrow keys to move the ▶ arrow to the answer you want.
  3. Press A (the Z key) to choose.
  4. Right answer ✅ — your move lands and you build a streak. Wrong ❌ — a hint appears and you try once more.

🌟Helpful features (tap ☰ Menu)

🗣️ Read aloud — the game speaks each question and the choices out loud, in a friendly voice. Perfect before Ethan can read fast. There's a Voice button to switch the speaker.
🎯 Focus — choose a Level (grade) and a Subject to practise. Leave it on Auto / Any to let the game pick.
📊 Report Card — see how he's doing by subject and grade, which questions he finds tricky, and earn ⭐ badges for mastering a subject.

👨‍🏫For the teacher (a note for Mom)

You don't need to know Pokémon at all. Here's the easy way to use it:

1. In ☰ Menu → Focus, set the Level to Ethan's grade and pick a Subject you want to work on today.
2. Turn on Read aloud so he can hear every question.
3. Play together — when he misses one, read the hint with him and let him try again. Praise the streak!
4. Once a week, open the Report Card to see what to practise next. This question bank below shows every question, so you can pre-teach.
